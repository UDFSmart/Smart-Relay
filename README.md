[![USOFT](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://smart.udfsoft.com)

This repository contains a set of firmware for the esp-01/esp-01s, designed to work with various types of relay modules.

<img src="docs/images/udfsoft_relay.png" alt="Device preview" width="300">

## SUPPORTED DEVICES

  + ESP8266 ESP-01S Relay v{X.X}
  + ESP8266 ESP-01 WIFI Wireless with {X}CH Relay Module Board

## EXTERNAL DEPENDENCIES

  * [Relay Controller](https://github.com/UDFSmart/Relay-Controller)
  * [UCommandExecutor](https://github.com/UDFSmart/UCommandExecutor)
  * [UFLogger](https://github.com/UDFSmart/UFLogger)
